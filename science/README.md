# Scientific account

1. [Model and results](model.md) defines the exposure, lower-moment nuisance and circular loss.
2. [Exact minimax receiver](minimax.md) gives the converse, finite Fourier readout and entanglement-depth comparison.
3. [Constructing the protected spectrum](arithmetic.md) fills spectral gaps using signed finite differences and proves the sharp asymptotic constant.
4. [Eight-qubit example](example.md) shows the full encoding and measurement with a small array.
5. [Fixed-aperture calibration](calibration.md) develops a depth-limited receiver and proves matching precision limits for systematic site phase and position errors.
6. [Phase and control errors](robustness.md) derives the nominal-lattice decoder’s exact phase response and quantifies its sensitivity to site errors and gate costs.
