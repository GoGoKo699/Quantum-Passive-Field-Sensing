# Learning route

Begin with the [eight-qubit curvature example](../science/example.md) to see the sensing task in one exposure. The [review bridge](ANCHOR.md) connects standard quantum metrology to the array model. The [30 milestones](MILESTONES.md) follow the argument from local phase encoding to global estimation on a phase circle and minimax precision on a bounded physical interval.

| What you want to understand | Where to start |
|---|---|
| The field, sensor geometry, and one-exposure budget | [Physical model](../science/model.md) |
| Why the next occupied charge matters more than a distant endpoint | [Minimax proof](../science/minimax.md) |
| How the array supplies a long consecutive spectrum | [Arithmetic construction](../science/arithmetic.md) |
| How preparation depth and calibration accuracy determine physical precision | [Fixed-aperture calibration](../science/calibration.md) |
| How site errors affect the nominal-lattice decoder | [Phase and control errors](../science/robustness.md) |
